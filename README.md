# Fortnite Trade Hub

Production-ready P2P Fortnite virtual economy trading platform with 82 complete features.

## Features

✅ Zero external API dependencies
✅ Custom AI fraud detection
✅ Multi-party escrow system
✅ Real-time price indexing
✅ Enterprise security
✅ Complete moderation system

## Quick Start

```bash
npm install
cp .env.example .env
npm run migrate
npm run seed
npm run dev
```

## Technology Stack

- Node.js + TypeScript
- PostgreSQL
- Socket.io
- Express.js
- Custom in-memory cache

Server runs at `http://localhost:3000`
